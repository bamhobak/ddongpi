# 💩 이피재피똥피

하늘에서 쏟아지는 똥을 피하는 웹 게임. **내 사진이 주인공**이 됩니다.

👉 **플레이: https://bamhobak.github.io/ddongpi/**

## 조작
- 📱 모바일: 화면을 손가락으로 좌우로 끌기
- 💻 PC: 마우스 이동 또는 ← → (A / D)
- 재시작: Space / Enter

## 주인공 스프라이트
| 상태 | 파일 |
|---|---|
| 왼쪽으로 이동 | `player_left.png` |
| 오른쪽으로 이동 | `player_right.png` |
| 똥에 맞은 직후 (1.5초) | `player_hurt.png` |
| 뚜니핑 타임에 떨어지는 것 | `poop_fever.png` (평상시엔 💩 이모지) |

- 멈춰 있으면 마지막으로 향했던 방향을 유지합니다
- 파일이 없으면 코드로 그린 기본 캐릭터로 넘어갑니다

이미지를 교체할 때는 배경이 투명한 PNG를 쓰고, `index.html` 의 `SPR` 값을 새 이미지에
맞게 조정해야 판정 원과 머리가 어긋나지 않습니다.

- `aspect` = 너비 / 높이
- `head` = 머리 지름 / 높이 — 이 값으로 머리 크기를 판정원(지름 64px)에 맞춥니다
- `cx`, `cy` = 이미지 안에서 머리 중심 위치 (비율)

### 히든 증강
특정 조건을 만족했을 때만 후보에 등장하며, 조건을 채워도 일반 증강의 **1/3 확률**로만 나옵니다.
선택 화면에서 보라색 `히든` 뱃지로 표시됩니다.

| | 증강 | 조건 | 효과 |
|---|---|---|---|
| 💥 | 정연핑 대폭주 | 🦸 정연핑 2개 이상 보유 | `정연핑!!!?? 무엇!!?!` — 정연핑이 1.3배로 커진다 (1회 한정) |
| 😋 | 배고픈 정연핑 | 🦸 정연핑 + 🧲 자석 보유 | 아이템이 뜨고 1.5초 뒤 정연핑이 화면 아래에서 날아와 대신 먹어준다. 가는 길의 똥도 부순다 (1회 한정) |
| ☔ | 우산 로켓배송 | ☂️ 우산 다발 보유 | 방패가 하나도 없으면 5초마다 하나씩 배송된다 (1회 한정) |
| 🌠 | 별핑별 | ⭐ 별빛 증폭 1개 이상 | 별을 먹으면 화면의 똥이 전부 사라진다. 각 똥의 점수를 10배로 주고 1.5초 무적 (1회 한정) |
| 👻 | 유령화 | 🎯 마운자로 이재 2개 이상 | 6초마다 1.5초씩 무적이 된다 (1회 한정) |
| 🕳️ | 블랙홀 | 🧲 자석 보유 | 자석 범위 1.5배, 뚜니핑 낙하물도 가까이 오면 끌려온다 (1회 한정) |
| 🌝 | 대왕 뚜니핑 군단 | 🌝 대왕 뚜니핑 보유 | 대왕 등장률 3배, 대왕 점수 2배 (1회 한정) |
| 🎰 | 도박꾼 | 레벨 5 이상 | 모든 점수 2배, 대신 목숨이 1로 고정된다 (1회 한정) |

하늘은 낮 → 노을 → 땅거미 → 밤으로 넘어가며, 레벨 15에서 완전한 밤이 되고 별이 뜹니다.
대신 아이템 등장 간격도 함께 짧아집니다 (레벨 1에서 약 7.5초 → 레벨 10에서 약 4.9초).
아이템은 종류마다 독립된 타이머로 등장합니다. 간격은 얼랑분포(지수 3개의 합)로 뽑아서
어느 정도 규칙적이면서도 매번 다르고, 종류별로 따로 돌기 때문에 여러 개가 한꺼번에
떨어지기도 합니다. 낙하 속도도 매번 다릅니다.
레벨 6부터는 초고속 똥이, 레벨 7부터는 아래 까다로운 똥들이 섞여 떨어집니다.
등장 확률은 레벨 7에서 4%로 시작해 레벨마다 4%p씩 올라 45%까지 늘어납니다.
이 셋은 색 기운으로 구분되고 **정연핑도 부수지 못합니다** — 직접 피하는 수밖에 없습니다.

| 색 | 종류 | 움직임 |
|---|---|---|
| 🟣 보라 기운 | 분열 | 화면 중간쯤에서 둘로 쪼개져 좌우로 흩어집니다 (조각은 평범한 똥) |
| 🔵 푸른 기운 | 지그재그 | 좌우로 크게 흔들리며 내려옵니다 |
| 🔴 붉은 세로선 | 레이저 | 2초간 떨어질 자리를 깜빡여 알려준 뒤 잔상을 남기며 내리꽂힙니다 (4,500px/s, 좌우 최대 35도) |
| 🟠 초거대 | 초거대 | 초대형 똥의 1.26배쯤 되는 덩치가 느릿하게 떨어집니다 |

특수똥은 **정연핑이 부수지 못합니다.** 대신 부딪히면 종류마다 다르게 반응하고, 정연핑은 그대로 지나갑니다.

| 특수똥 | 정연핑과 부딪히면 |
|---|---|
| 🟣 분열 | 그 자리에서 곧바로 쪼개집니다 (예정 높이보다 일찍) |
| 🔵 지그재그 | 흔들리던 방향이 반대로 뒤집힙니다 |
| 🟠 초거대 | 세 조각으로 갈라져 좌·중앙·우로 흩어집니다 (조각은 평범한 똥) |
| 🔴 레이저 | 아무 반응 없이 지나갑니다 |

## 🏆 이번 주 TOP 10
모든 사람이 하나의 랭킹을 공유합니다. 게임이 끝났을 때 TOP 10 안에 들면 이름을 남길 수 있습니다.

순위표에는 **한 기기당 한 줄만** 오릅니다. 기록은 모두 저장하되 조회할 때 기기별 최고 점수만
골라내는 방식이라, 한 사람이 여러 순위를 차지하지 않습니다.

랭킹은 **매주 월요일 0시(한국시간)에 초기화**됩니다. 실제로 기록을 지우는 게 아니라 조회할 때
그 주 월요일 이후 기록만 가져오는 방식이라, 예약 작업이 실패해서 초기화가 안 되는 일이 없고
지난 주 기록도 DB에 그대로 남습니다. 보는 사람의 기기 시간대와 상관없이 항상 한국시간 기준입니다.

설정 방법:
1. [supabase.com](https://supabase.com/dashboard) 에서 이 게임 전용 프로젝트를 새로 만듭니다 (무료).
2. SQL Editor 에 [`supabase_leaderboard.sql`](supabase_leaderboard.sql) 내용을 붙여넣고 Run.
3. Settings → API 의 **Project URL** 과 **publishable(anon) key** 를 `index.html` 상단 `SB_URL`, `SB_KEY` 에 넣습니다.

`SB_URL`/`SB_KEY` 가 비어 있으면 랭킹만 표시되지 않고 게임은 정상 동작합니다.
등록된 기록은 수정·삭제가 불가능하며(RLS), 이름은 12자·점수는 범위 제한이 걸려 있습니다.

## 플레이 기록 수집 (개발자용)
판이 끝날 때 점수·레벨·생존 시간·별 개수·**선택한 증강 목록**을 `ddongpi_runs` 테이블에
익명으로 남깁니다. 이름이나 기기 정보는 보내지 않습니다.

익명 키에는 **insert 권한만** 주고 select 는 막아뒀기 때문에, 플레이어는 이 데이터를
전혀 볼 수 없고 개발자만 Supabase 대시보드에서 조회할 수 있습니다.
설치와 통계 조회문은 [`supabase_analytics.sql`](supabase_analytics.sql) 참고.
