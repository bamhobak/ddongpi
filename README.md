# 💩 이피저피똥피 (Zig Zag Poop)

하늘에서 쏟아지는 똥을 피하는 웹 게임. **내 사진이 주인공**이 됩니다.

👉 **플레이: https://bamhobak.github.io/ddongpi/**

> 이 문서는 `index.html` 의 실제 값을 옮겨 적은 것입니다. 숫자를 고쳤으면 여기도 같이 고쳐 주세요.
> 마지막으로 맞춰 본 판: **v0.8.66**

## ⚔️ 대전모드 (v0.8.24 한 폰 · v0.8.25 두 폰)
시작하기를 누르면 **[방 만들기] · [방 참가](방 번호 4자리) · [한 폰으로 둘이서]** 를 고릅니다.

  직업 능력·펫 없음, 순위표에 오르지 않습니다.

  연달아 밟을 수 있습니다(v0.8.28 에 풀린 뒤 보호 시간을 뺐다).
  **아래에서 들이받기**: 상대가 위에 있을 때 내가 뛰어오르는 중에 머리로 치면, 밟히는 대신 위에 있던 상대가 보통 점프의 두 배 높이로 날아갑니다.
  대신 몸이 올라가서 떨어지는 똥에 맞기 쉽습니다. 높이 약 105, 떠 있는 시간 약 0.6초. 두 폰은 높이·빠르기를 주고받아 앞당겨 그립니다.

## 점수

모든 점수에는 **공통 배율(`scoreMul`)** 이 곱해집니다. 기본 눈금이 **3배**이고, 아래 것들이 거기에 더 곱해집니다.

| 공통 배율 | 값 |
|---|---|
| 기본 눈금 | ×3 |
| 🥕 하트 당근거래 | 한 장마다 ×1.2 (최대 5장) |
| 🕳️ 블랙홀 안 (221초~) | ×2 |
| 🎈 부양사 높이 | 바닥 ×1 → 꼭대기 ×2 |
| 🙏 무소유 무피격 | 1 + 0.1 × 안 맞고 버틴 초 (상한 없음, 맞으면 시간의 1/4 만 깎임) |
| 💩 똥묻히기 (방울이) | 1 + 오염도/100 (100%면 ×2) |
| 🔮 예언 | 점수 두 배 ×2 · 운명의 주사위 ×3 |

그 위에서 항목별로:

| 항목 | 점수 |
|---|---|
| 생존 시간 | 초당 **50 × 레벨** |
| 🎯 명당 (점술가 예언) | 명당 위에 서 있는 동안 생존 점수의 **4배** |
| 💩 일반 똥을 흘려보냄 | **10 × 레벨 × 거리 배율(0.5 ~ 3배)** — 아래 [아슬!](#-아슬--가까이-보낼수록-비싸다) 참고 |
| ⭐ 별 획득 | **2,000 × 먹은 횟수** — 1번째 2,000 · 2번째 4,000 · 3번째 6,000 … (한 판마다 리셋) |
| 🔥 뚜니핑 낙하물을 몸으로 받음 | 크기별 **3 / 5 / 10 × 레벨** (대왕 뚜니핑 138) |

### ✨ 아슬! — 가까이 보낼수록 비싸다

흘려보낸 똥은 **떨어지는 내내 히트박스와 가장 가까웠던 틈**으로 값이 갈립니다.
구석에 숨어 있으면 저절로 손해가 되고, 아슬아슬하게 보낼수록 점수가 붙습니다.

| 틈 (히트박스 바깥으로) | 배율 | 표시 |
|---|---|---|
| **20px** 이내 | **3배** | 캐릭터 머리에서 땀방울이 튄다 + 소리 |
| 150px 이내 | 1.5배 | — |
| 150 ~ 380px | 1.5 → 0.5배로 완만하게 | — |
| 380px 밖 | 0.5배 | — |

스침 판정은 **진짜 아슬아슬할 때만** 붙도록 박하게 잡았습니다 (v0.7.77 에서 40px → 20px).
연출도 일부러 작게 뒀습니다 — 한 판에 수십 번 일어나는 일이라
**글자(`아슬!`)와 짧은 느린 화면은 화면이 시끄러워져서 뺐습니다.**
남은 건 **캐릭터 머리에서 튀는 땀방울**(스친 쪽의 반대편으로 1~2방울)과 소리뿐이고,
소리만 0.25초마다 한 번씩 울립니다. 놀란 건 똥이 아니라 캐릭터라, 효과를 똥이 아니라 몸에 붙였습니다.

- **초반에는 차이를 좁혀 둡니다** — 1레벨은 배율 차이의 35%만, 6레벨에서 온전해집니다.
- 무적인 동안(맞은 뒤 1초, 뚜니핑 타임)에는 틈을 **재지 않습니다** — 공짜 스침을 막기 위해서.
  한 번도 못 잰 똥은 배율 없이 1배를 줍니다.
- **방귀 대시로 뚫고 지나간 똥은 스침으로 잡힙니다** (지나온 길을 훑어서 처리).
- 게임 중에는 세지 않고, **게임오버 화면에만** `✨ 아슬 N번` 으로 남습니다.

실측(무적 테스트 모드 70초, 쉬었음 청년) — 똥 점수는 전체의 **16~31%** 라, 3배를 다 받아도
총점이 배로 뛰지는 않습니다.

### 🗼 똥탑등반 (옛 이름 노템전 · 2026-09-19 모두에게 열림)

**기록이 점수가 아니라 올라간 거리(m)** — 레벨 하나 = 100m, 순위표도 m 입니다.
아이템·증강 없이(코인만 나옴) **모든 캐릭 공통 스테이지**를 똑같이 오릅니다.
**직업은 방울이로 고정(비누방울 없이) · 펫 없이.**

- 레벨 하나 = **8초** = 패턴 하나 (채보 4줄)
- 레벨 번호로 정해진 섞기로 **일곱 벌 × 여덟 판 × 여덟 도막** 중에서 뽑습니다 —
  누구나 같은 레벨에는 같은 패턴
- 두 레벨마다 한 단계 어려워지고, 볼 틈은 1.9초 → 0.8초
- 똥 자리는 판마다 좌우 뒤집기·격자 이동
- 난이도 체감은 1레벨이 예전 4레벨 수준, 4~5레벨에 은하수 난이도
- 한 줄에 똥 최소 3개, 옛 채보 60% + 새 패턴 40%
  - **굽잇길**(20%) — 빈 길이 계단처럼 쓸린다
  - **널뛰기**(10%) — 빈 길이 양 끝을 오간다
  - **느린 파도**(10%, v0.8.03) — 다섯 칸 중 **한 칸만 비는 벽**이 아주 느리게(보통의 3분의 1 속도) 내려온다.
    빈 칸이 사인 곡선을 그리며 좌우로 쓸려서, 화면에 예닐곱 겹이 겹쳐 굽이치는 길로 보인다.
    벽은 통째로 좌우로 일렁이고(거의 바닥까지), **가운데 줄에서만 속도가 1.7배로 확 빨라졌다가** 다시 느려진다
- 절반쯤의 레벨은 **사선 낙하** (비스듬히 날아와 머리 높이에서 제 칸에 선다)

## 🏆 이번 주 TOP 10

모든 사람이 하나의 랭킹을 공유합니다. 게임이 끝났을 때 TOP 10 안에 들면 이름을 남길 수 있습니다.
순위표는 **스테이지마다 따로** 섭니다 (똥탑등반은 점수 대신 m).

순위표에는 **한 기기당 한 줄만** 오릅니다. 기록은 모두 저장하되 조회할 때 기기별 최고 점수만
골라내는 방식이라, 한 사람이 여러 순위를 차지하지 않습니다.

랭킹은 **매주 월요일 0시(한국시간)에 초기화**됩니다. 실제로 기록을 지우는 게 아니라 조회할 때
그 주 월요일 이후 기록만 가져오는 방식이라, 예약 작업이 실패해서 초기화가 안 되는 일이 없고
지난 주 기록도 DB에 그대로 남습니다. 보는 사람의 기기 시간대와 상관없이 항상 한국시간 기준입니다.

설정 방법:
1. [supabase.com](https://supabase.com/dashboard) 에서 이 게임 전용 프로젝트를 새로 만듭니다 (무료).
2. SQL Editor 에 [`sql/supabase_leaderboard.sql`](sql/supabase_leaderboard.sql) 내용을 붙여넣고 Run.
3. Settings → API 의 **Project URL** 과 **publishable(anon) key** 를 `index.html` 상단 `SB_URL`, `SB_KEY` 에 넣습니다.

`SB_URL`/`SB_KEY` 가 비어 있으면 랭킹만 표시되지 않고 게임은 정상 동작합니다.
등록된 기록은 수정·삭제가 불가능하며(RLS), 이름은 12자·점수는 범위 제한이 걸려 있습니다.

익명 키에는 **insert 권한만** 주고 select 는 막아뒀기 때문에, 플레이어는 이 데이터를
전혀 볼 수 없고 개발자만 Supabase 대시보드에서 조회할 수 있습니다.
설치와 통계 조회문은 [`sql/supabase_analytics.sql`](sql/supabase_analytics.sql) 참고.

## 그림 뽑기 (OpenAI)

[`tools/gen_sprite.py`](tools/gen_sprite.py) — OpenAI 이미지 API(기본 `gpt-image-2`)로 캐릭터 그림을 뽑습니다.
키는 환경변수 `OPENAI_API_KEY` 에서만 읽습니다 (파일에 적지 않음).

```
python tools/gen_sprite.py <이름> "<프롬프트>" --ref <화풍 참고 그림> ... [--n 4]
```

- `--ref` 로 지금 게임 그림을 넣으면 그 **화풍**(굵은 테두리·파스텔 명암·큰 머리)을 따라갑니다.
  프롬프트에 "참고 그림은 화풍만, 캐릭터는 따라 하지 말 것"을 꼭 적어야 새 캐릭터가 나옵니다.
- 배경을 투명하게 받아 여백을 자르고 **높이 320px** 로 맞춰 `assets/_gen/<이름>_<번호>.png` 에 남깁니다
  (`_gen` 은 배포하지 않음). 고른 것만 `assets/` 로 옮기고, `index.html` 의 `SPR_*` 규격
  (`aspect`·`head`·`cx`·`cy`·`adj`, 방울이는 비누방울 `bcx`·`bcy`·`brr` 까지)을 새 그림에 맞춰 잽니다.
- 한 번에 4장 · 약 2.5분.
- 배경 그림은 `--bg opaque --raw --size 960x2304` (지대 배경 원래 크기 그대로 받는다, 4장 약 1.5분).
- [`tools/gen_zones.py`](tools/gen_zones.py) — 지대 2~18 을 한꺼번에 (지대마다 후보 2장, 2개씩 동시에). 화풍 참고는 1단계의 **하늘 부분만** 잘라 쓴다 —
  통째로 넣었더니 우주 지대까지 발밑에 잔디 언덕을 그렸다. '마지막엔 블랙홀'이라고 적으면 앞 지대에도 블랙홀을 그려서 13단계까지는 금지 문구를 붙인다.
  OpenAI 분당 한도 때문에 4개 동시는 막힌다 (2개 + 한도에 걸리면 기다렸다 다시).

### ChatGPT 구독으로 뽑기 (Codex) — 기본

[`tools/gen_codex.py`](tools/gen_codex.py) — 쓰는 법·결과 규격이 `gen_sprite.py` 와 똑같고, API 키 대신 **Codex CLI 의 ChatGPT 로그인**을 씁니다
(VS Code 의 Codex 확장이 로그인돼 있으면 됨). 크레딧이 안 나가고 구독의 Codex 사용 한도에서 빠집니다.

```
python tools/gen_codex.py <이름> "<프롬프트>" --ref <참고 그림> ... [--n 4] [--jobs 2]
```

- Codex 에 내장된 이미지 생성 도구가 그립니다. 한 번에 한 장이라 `--n` 번 부르고, `--jobs` 개씩 동시에 (2장 동시 약 1분 반).
- 크기·품질은 지정할 수 없고 도구가 정합니다 (보통 1200px 안팎, 투명 배경).
- 구독 한도에 걸리면 한도가 풀릴 때까지 기다립니다. `gen_sprite.py`(API)는 돈이 나가서 **허락받았을 때만** 씁니다.

### 아이콘 (이모지 대신 그림) — v0.8.15
기기마다 다르게 보이던 이모지(증강·직업·펫·지대·버튼·메달 등 90여 종)를 방울이 그림체 아이콘으로 바꿔 그립니다.
- 목록: [`tools/icon_list.py`](tools/icon_list.py) — `NEW`(새로 뽑는 것: 이모지·이름·그릴 것)와 `REUSE`(코인·별·달·우산·하트·펫처럼 이미 있는 게임 그림을 그대로 쓰는 것).
- 뽑기: `python tools/gen_icons.py` — Codex(구독)로 6개씩 동시에, 한도에 걸리면 멈춥니다(한도가 풀린 뒤 다시 돌리면 이어서). 이미 뽑은 것은 건너뜁니다.
  OpenAI API(`gen_icons.py api`)는 돈이 나가서 **허락받았을 때만** 씁니다.
- 시트: `python tools/build_icons.py` — 전부 `assets/icons.webp` 한 장(칸 96px, 10칸씩)으로 모으고 `index.html` 의 `ICON_KEYS`(칸 순서)를 고쳐 씁니다.
  미리보기는 `assets/_gen/_preview/icons_sheet.png`.
- 게임에서는 **코드를 고치지 않고** 이모지가 저절로 그림이 됩니다:
  화면 글자(버튼·카드·게임오버)는 이모지를 `<span class="emj">` 로 감싸 배경으로 그림을 깔고(글자는 숨기기만 해서 `textContent` 는 그대로),
  캔버스 글자(HUD·떠오르는 글자)는 `fillText` 를 감싸 이모지 자리에 그림을 그립니다(자리 폭은 원래 이모지 폭).
- 목록에 없거나 그림이 아직 안 온 이모지는 원래 이모지로 나옵니다. 새 이모지를 쓰면 `icon_list.py` 에 한 줄 넣고 뽑기 → 시트 순서로.
