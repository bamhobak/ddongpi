# 💩 이피재피똥피

하늘에서 쏟아지는 똥을 피하는 웹 게임. **내 사진이 주인공**이 됩니다.

👉 **플레이: https://bamhobak.github.io/ddongpi/**

## 조작
- 📱 모바일: 화면을 손가락으로 좌우로 끌기
- 💻 PC: 마우스 이동 또는 ← → (A / D)
- 재시작: Space / Enter

## 사진 넣기
- 게임 화면에서 **📷 주인공 사진 넣기** 버튼 → 사진 선택
- PC에서는 사진을 화면에 끌어다 놓아도 됨
- 한 번 넣으면 브라우저에 저장되어 다음에도 유지됨 (내 기기 안에만 저장, 서버로 전송되지 않음)

## 아이템
| | 효과 |
|---|---|
| 💩 | 맞으면 목숨 -1 |
| 🧻 | 🔥 **피버타임 10초** — 무적 + 똥이 폭포처럼 쏟아짐, 부수는 대로 +10점 |
| ☂️ | 한 방 막아주는 방패 |
| ⭐ | 보너스 +50점 |
| ❤️ | 목숨 +1 (최대 5) |

10초마다 레벨업 — 똥이 더 빠르고 더 많이 떨어집니다. 레벨 6부터는 초고속 똥도 섞여 떨어집니다.
